結論網站整體流量來源站內頁面行為與詢問廣告數據待處理

結論

本期瀏覽少 11.31%、工作階段少 5.97%，但表單送出 58 → 65，沒有跟著掉。流量少在自然搜尋與直接進站，站內少在作品內頁與活動頁；付費流量撐住人數，停留卻最短。

  1. 量變少，逛得也變淺瀏覽 17,687 → 15,686(-11.31%)，工作階段 11,462 → 10,778(-5.97%)，使用者 9,997 → 9,448(-5.49%)；平均單次工作階段參與時間 30.3 秒 → 26.0 秒。
  2. 少的是自然搜尋與直接進站，付費持平減少的 684 個工作階段裡，Organic Search 少 381(佔 55.7%)、Direct 少 219(佔 32.0%)。Paid Social、Display、Paid Search 合計 3,983 → 4,060(+1.93%)，佔本期 37.7%。
  3. 列表頁沒少，點進作品的人少了作品列表頁瀏覽 6,565 → 6,317(-3.78%)，作品內頁 3,159 → 2,578(-18.39%)，是全站減少最多的一塊。view item ÷ view item list 由 58.58% 降到 46.18%。
  4. 詢問沒有跟著掉表單送出(form_submit)58 → 65(+12.07%)；LINE 點擊 33 → 15；加上電話點擊，三者合計 91 → 83。前段的 contacu us 487 → 374(-23.20%)、form_start 155 → 109(-29.68%)有下降，但開始填表後送出的比例由 37.42% 升到 59.63%。
  5. 近三分之二的流量幾乎沒停留Direct、Paid Social、Display 合計 6,888 個工作階段(63.9%)，平均停留 4.9 秒；Organic Search、Paid Search、Referral 合計 3,596 個(33.4%)，平均停留 67.4 秒。
判讀

這一期流量下滑，還沒有反映在表單送出上：來的人少了、看得淺了，送出表單的次數反而多 7 次。要留意三件事。第一，自然搜尋少了 11.67%，它是唯一量大又會停留的來源。第二，住宅作品列表頁一頁就佔全站瀏覽 31.8%，每人只停 8.5 秒，而從列表點進作品的比例在下降。第三，Meta 流量廣告本月花費 5,309 元(到 11/23)，對應 Paid Social 2,900 個工作階段、平均停留 3.0 秒，貢獻的是人數，不是瀏覽。
